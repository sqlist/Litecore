# ADR-0002：信道门限只用于首次接入

## 状态

已接受。

## 决策

信道模型只负责为一次注册尝试计算两个输出：信号强度（dBm）和SINR（dB）。模型不拥有接入策略，可以通过`ChannelModel`接口替换。

AMF负责接入门限：信号强度不得低于-110 dBm，SINR不得低于0 dB。门限只在UE不存在、准备开始首次注册时检查。已经处于`REGISTERED`状态的UE再次调用注册接口时走幂等返回，不会因为新的信道样本被注销。

## 范围边界

当前系统没有周期信道上报、无线链路失败检测、切换或注册后的接入撤销。UE注册后信道恶化仍保持在线。这是教学范围限制，不应描述为完整的移动性或无线资源管理能力。

## 后果

- 答辩中的“可替换”特指替换计算信号强度和SINR的模型实现。
- 门限变化只需修改AMF接入策略，不需要修改信道模型。
- 如需根据信道质量持续踢下线，必须新增独立的测量上报和状态迁移设计，不能复用一次性注册参数冒充持续监测。
